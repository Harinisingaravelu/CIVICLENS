# Product Specification

## Problem
Public-grievance datasets contain operational signals such as receipts, disposals, pending workload and ageing. The product turns these into an analytical workspace.

## Users
- Data analyst
- Policy/research analyst
- Department operations analyst
- Student portfolio reviewer

## Core questions
1. What is the current grievance workload?
2. How does disposal compare with receipts?
3. Where is pending workload concentrated?
4. What does pending ageing look like?
5. How has workload changed over time?
6. What data-quality limitations affect interpretation?

## Guardrails
CIVICLENS must not present project metrics as official government rankings or infer causes that the source data does not establish. AI answers must cite the dataset snapshot and distinguish calculation from interpretation.

## V1 modules
- Executive Overview
- State Explorer
- Pending Ageing
- Trend Analytics
- Data Quality
- Gemini Analytics Copilot
