# Official Data Source

Primary source:
https://pgportal.gov.in/darpgdashboard

Snapshot:
01/01/2026–25/09/2026

Coverage:
State/UT grievance status.

Fields captured:
Received, disposed, disposal percentage (derivable), pending 0–60 days, 60–180 days, 180–365 days, and more than one year.

Important source caveat:
The CPGRAMS dashboard states that disposals include carry-forward receipts from previous year(s).

CIVICLENS does not claim to be an official Government of India dashboard. It is an independent analytics project built from publicly displayed official data.
